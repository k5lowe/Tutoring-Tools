Q: Evaluate $\displaystyle\lim_{x \to 0} x^2 \sin\left(\dfrac{1}{x}\right)$, justifying your answer.
A: $0$
S: The limit cannot be split into a product of limits, because $\sin\left(\dfrac{1}{x}\right)$ has no limit at $0$ — it oscillates faster and faster. S: The numerator factors as $(x - {{a}})(x + {{a}})$, so for $x \ne {{a}}$ the function is just $x + {{a}}$. That has the limit ${{a}} + {{a}} = {{2*a}}$ at $x = {{a}}$, but $f$ itself is undefined there because the original denominator vanishes. A discontinuity where the limit exists but the function does not match it is called removable — the graph has a single hole, and filling it in with $f({{a}}) = {{2*a}}$ makes $f$ continuous.

Q: Name the three kinds of discontinuity a function can have at a point, and give an example of each.
A: Removable, where the limit exists but the function is undefined or has the wrong value there — for example $\dfrac{x^2 - 1}{x - 1}$ at $x = 1$. Jump, where both one-sided limits exist but differ — for example $\dfrac{|x|}{x}$ at $x = 0$. Infinite, where at least one one-sided limit is $\pm\infty$ — for example $\dfrac{1}{x}$ at $x = 0$.
S: The classification comes from asking two questions in order. Do both one-sided limits exist and agree? If yes, the discontinuity is removable. If they exist but disagree, it is a jump. If at least one is infinite, it is an infinite discontinuity. There is a fourth possibility that resists all three labels — an essential oscillating discontinuity such as $\sin\left(\dfrac{1}{x}\right)$ at $x = 0$, where neither one-sided limit exists at all.

@ Calculus 1 > Limits > L'Hopital's rule | d5 | tags: limits, lhopital
Q: Explain why L'Hopital's rule cannot be used on $\displaystyle\lim_{x \to 0} \dfrac{\sin x}{x + 1}$, and evaluate the limit.
A: The limit is $0$. L'Hopital's rule does not apply because substituting gives $\dfrac{0}{1}$, which is not an indeterminate form.
S: The rule only applies to $\dfrac{0}{0}$ and $\dfrac{\infty}{\infty}$. Here the denominator tends to $1$, not $0$, so the quotient is perfectly well behaved and direct substitution gives $\dfrac{\sin 0}{0 + 1} = \dfrac{0}{1} = 0$. Applying the rule anyway would give $\dfrac{\cos x}{1} \to 1$, which is wrong — checking the form first is not a formality. This is the most common way the rule is misused.

@ Calculus 1 > Limits > The intermediate value theorem | d4 | tags: limits, continuity, ivt
Q: Show that $x^3 {{term(a,'x')}} - {{b}} = 0$ has a solution between $0$ and $1$.
A: Let $f(x) = x^3 {{term(a,'x')}} - {{b}}$. It is a polynomial, so it is continuous on $[0, 1]$. Now $f(0) = -{{b}} < 0$ and $f(1) = 1 + {{a}} - {{b}} = {{1 + a - b}} > 0$. Since $f$ is continuous and changes sign, the intermediate value theorem gives a $c$ in $(0, 1)$ with $f(c) = 0$.
S: Three things have to be said for the argument to be complete: that the function is continuous on the closed interval, that the two endpoint values have opposite signs, and only then the conclusion. Continuity is doing real work — without it a function can jump straight over zero. Note what the theorem does not give you: it says a root exists, not where it is or how many there are.

Q: Evaluate $\displaystyle\lim_{x \to \infty} \left(1 + \dfrac{ {{a}} }{x}\right)^x$.
A: $e^{ {{a}} }$
S: The starting point is the definition $\displaystyle\lim_{n \to \infty}\left(1 + \dfrac{1}{n}\right)^n = e$. Substituting $x = {{a}}n$ turns the expression into $\left(1 + \dfrac{1}{n}\right)^{ {{a}}n } = \left[\left(1 + \dfrac{1}{n}\right)^{n}\right]^{ {{a}} } \to e^{ {{a}} }$. Alternatively take logarithms: $x\ln\left(1 + \dfrac{ {{a}} }{x}\right) \to {{a}}$, since $\ln(1 + u) \approx u$ for small $u$, so the original tends to $e^{ {{a}} }$. The form here is $1^\infty$, which is indeterminate — the $1$ inside is not enough to force the answer to be $1$.
