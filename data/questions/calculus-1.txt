Q: Evaluate $\displaystyle\lim_{x \to 0} x^2 \sin\left(\dfrac{1}{x}\right)$, justifying your answer.
A: $0$
S: The limit cannot be split into a product of limits, because $\sin\left(\dfrac{1}{x}\right)$ has no limit at $0$ — it oscillates faster and faster. Instead bound it: $-1 \le \sin\left(\dfrac{1}{x}\right) \le 1$ for every $x \ne 0$, so multiplying by $x^2 \ge 0$ gives $-x^2 \le x^2\sin\left(\dfrac{1}{x}\right) \le x^2$. Q: Name the three kinds of discontinuity a function can have at a point, and give an example of each.
A: Removable, where the limit exists but the function is undefined or has the wrong value there — for example $\dfrac{x^2 - 1}{x - 1}$ at $x = 1$. Jump, where both one-sided limits exist but differ — for example $\dfrac{|x|}{x}$ at $x = 0$. Infinite, where at least one one-sided limit is $\pm\infty$ — for example $\dfrac{1}{x}$ at $x = 0$.
S: The classification comes from asking two questions in order. Do both one-sided limits exist and agree? If yes, the discontinuity is removable. If they exist but disagree, it is a jump. If at least one is infinite, it is an infinite discontinuity. There is a fourth possibility that resists all three labels — an essential oscillating discontinuity such as $\sin\left(\dfrac{1}{x}\right)$ at $x = 0$, where neither one-sided limit exists at all.

Q: Show that $x^3 {{term(a,'x')}} - {{b}} = 0$ has a solution between $0$ and $1$.
A: Let $f(x) = x^3 {{term(a,'x')}} - {{b}}$. It is a polynomial, so it is continuous on $[0, 1]$. Now $f(0) = -{{b}} < 0$ and $f(1) = 1 + {{a}} - {{b}} = {{1 + a - b}} > 0$. Since $f$ is continuous and changes sign, the intermediate value theorem gives a $c$ in $(0, 1)$ with $f(c) = 0$.
S: Three things have to be said for the argument to be complete: that the function is continuous on the closed interval, that the two endpoint values have opposite signs, and only then the conclusion. Continuity is doing real work — without it a function can jump straight over zero. Note what the theorem does not give you: it says a root exists, not where it is or how many there are.

S: Product rule with $u = x$ and $v = \arctan x$: $f' = 1 \cdot \arctan x + x \cdot \dfrac{1}{1 + x^2}$. The answer keeps an inverse trigonometric function in it, which is normal — unlike the logarithm case, the arctangent does not disappear when only one factor is differentiated.

Q: Differentiate $f(x) = e^{\sin x}$.
A: $f'(x) = e^{\sin x}\cos x$
S: Chain rule with the outer function $e^{u}$ and $u = \sin x$: $f' = e^{u}u' = e^{\sin x}\cos x$. Read the layers from the outside in — exponential first, then what is in the exponent — and the rule writes itself.

Q: Differentiate $f(x) = \dfrac{\sin x}{x}$.
A: $f'(x) = \dfrac{x\cos x - \sin x}{x^2}$
S: The quotient rule gives $\dfrac{(\cos x)(x) - (\sin x)(1)}{x^2}$. There is no further simplification — unlike the polynomial quotients where the $x$ terms cancel, this one is as tidy as it gets. Note the order in the numerator: bottom times the derivative of the top, minus top times the derivative of the bottom.

Q: Find the ${{4*k}}$th derivative of $f(x) = \sin x$.
A: $\sin x$
S: Differentiating sine cycles with period four: $\sin x \to \cos x \to -\sin x \to -\cos x \to \sin x$. Since ${{4*k}}$ is a multiple of $4$, the cycle returns to where it started, so the ${{4*k}}$th derivative is $\sin x$ again. For any $n$, only $n$ modulo $4$ matters.
V: k = int 1..6

@ Calculus 1 > Derivatives > Implicit differentiation | d5 | tags: derivatives, implicit, trigonometry
Q: Given $\sin(xy) = x$, find $\dfrac{dy}{dx}$.
A: $\dfrac{dy}{dx} = \dfrac{1 - y\cos(xy)}{x\cos(xy)}$
S: Differentiate both sides with respect to $x$, using the chain rule on the left and the product rule inside it: $\cos(xy)\left(y + x\dfrac{dy}{dx}\right) = 1$. Expanding, $y\cos(xy) + x\cos(xy)\dfrac{dy}{dx} = 1$. Collecting the derivative on one side gives $\dfrac{dy}{dx} = \dfrac{1 - y\cos(xy)}{x\cos(xy)}$. The answer involves both $x$ and $y$, which is normal for implicit differentiation — the curve is not a function of $x$ alone.
